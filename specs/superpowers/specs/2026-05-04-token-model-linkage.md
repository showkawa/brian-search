# Token → 模型选择 → 招聘页联动

**日期**: 2026-05-04
**状态**: 已确认

## 问题

设置页配置了 API Key 后，招聘页不知道哪些模型可用。用户输入 Key 测试连接成功，但招聘页的模型选择器仍然显示所有 8 个选项（包含未配置 Key 的）。用户可能在招聘页选择了一个没有 Key 的模型，到真正调用时才报错。

## 目标

1. 设置页：每个 API Key 下增加该提供商的模型选择器，选定默认模型
2. 招聘页：模型选择器只显示已配置 Key 的提供商的模型；未配置时显示引导横幅
3. 两者通过 config.json 联动

## 设计

### 设置页改动

每个 API Key 卡片增加模型选择器：

```
🤖 大模型 API
┌──────────────────────────────────────────────┐
│ 智谱 GLM  [sk-xxx...  ]  ✓ 已连接  [测试]   │
│ 默认模型  [GLM-4 Flash ▼]                    │
├──────────────────────────────────────────────┤
│ 通义 Qwen  [          ]  未配置     [测试]   │
│ 默认模型  [Qwen Plus   ▼] (灰色禁用)         │
├──────────────────────────────────────────────┤
│ DeepSeek  [sk-xxx...  ]  ✓ 已连接  [测试]   │
│ 默认模型  [DeepSeek Chat ▼]                  │
└──────────────────────────────────────────────┘
```

模型列表从 `_MODEL_OPTIONS` 按 provider 过滤。选择后保存到 `config.json` → `model.{provider}_model` 字段。

### 招聘页改动

**模型选择器过滤**：只显示已配置 Key 的提供商模型。

**未配置引导**：

所有三组 Key 都为空时：

```
⚠️ 尚未配置任何大模型 API Key
请先在 账户配置 中设置至少一个模型的 Key
                        [前往配置 →]
```

部分配置时，缺少的用文字提示替代 Select：

```
[GLM-4 Flash ▼]  ·  Qwen 未配置，前往账户配置
```
